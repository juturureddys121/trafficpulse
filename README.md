# PromptWars x Techverse Demo

This project is a polished prototype for the PromptWars hackathon challenge: build a Gemini-powered application that turns messy, real-world input into structured and verified actions.

## Run locally

From the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` - challenge board and app layout
- `styles.css` - layout, branding, and responsive styling
- `script.js` - intent detection and structured action generation

## Features

- Input area for messy, unstructured user context
- Scenario detection for medical, traffic, weather, and news use cases
- Structured action plan with risk and verification metadata
- Responsive, polished single-page interface inspired by the provided hackathon brief
